# 交通費・交際費ログ

交通費と交際費を素早く記録し、期間別の集計やCSV出力まで端末内で完結できるAndroidアプリです。

[Google Playで見る](https://play.google.com/store/apps/details?id=com.kotsuhi.manager)

![交通費・交際費ログ](mobile/assets/images/feature-graphic-1024x500.png)

## アプリについて

電車、バス、タクシー、食事、カフェなど、日常的に発生する交通費と交際費を記録・管理できます。前回入力、頻出金額、テンプレートを利用して、繰り返し発生する支出を少ない操作で登録できるようにしています。

## 主な機能

- 交通費・交際費の記録、編集、削除
- カテゴリに応じたサブカテゴリの選択
- 交通費の片道・往復入力
- 前回入力した内容の再利用
- 頻出金額の候補表示
- 支出テンプレートの作成、編集、並び替え
- 今月・先月・過去3か月の集計
- カテゴリ・サブカテゴリ別の内訳表示
- 支出ごとの満足度と期間別の振り返り
- 今月または全期間のCSV出力
- 端末内へのデータ保存とオフライン利用

## 設計で重視したこと

### 繰り返し入力の負担を減らす

通勤などで同じ支出を何度も入力する場面を想定し、前回入力、頻出金額、テンプレート、往復入力を用意しています。

### 記録した内容を振り返れる

合計金額だけでなく、カテゴリ別の割合、サブカテゴリ別の金額、支出に対する満足度を期間ごとに確認できます。

### データを端末内で管理する

記録した内容はSQLiteへ保存し、クラウドへの同期や外部サービスへの送信を行いません。通信環境がない場所でも利用できます。

### 変更しやすいコード構成

画面、アプリケーション処理、支出のルール、SQLiteへの保存処理を分離しています。機能追加や保存方法の変更が、ほかの部分へ影響しにくい構成を目指しています。

## 使用技術

- TypeScript
- React Native
- Expo / Expo Router
- SQLite
- Drizzle ORM
- Jest

## アプリの構成

```text
画面
  ↓
アプリケーション処理
  ↓
支出・テンプレートのルール
  ↓
SQLiteへの保存
```

現在Google Playで公開しているアプリは `mobile/` 配下です。`backend/` は現在の公開アプリでは使用していません。

## 開発環境

```bash
cd mobile
npm install
npx expo start
```

型とテストの確認は次のコマンドで実行します。

```bash
npx tsc --noEmit
npm test -- --runInBand
```
